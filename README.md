# HomeCare | رعايتك في بيتك

مشروع تخرج تعليمي لبناء منصة ويب/PWA لتنظيم الرعاية الصحية المنزلية.

## محتويات المشروع
- `index.html`: واجهة التطبيق.
- `styles.css`: التصميم المتجاوب.
- `app.js`: تسجيل الدخول، إدارة الصفحات، النماذج، وعرض البيانات.
- `config.js`: إعداد اتصال Supabase.
- `supabase-schema.sql`: الجداول وسياسات Row Level Security.
- `manifest.webmanifest` و`service-worker.js`: دعم التثبيت والعمل دون اتصال لملفات الواجهة.
- `assets/icon.svg`: أيقونة التطبيق.

## تشغيل سريع
1. ارفع محتويات المجلد إلى مستودع GitHub.
2. فعّل GitHub Pages من Settings > Pages > Deploy from a branch، واختر `main` ومجلد `/ (root)`.
3. افتح رابط GitHub Pages. الواجهة تعمل في وضع العرض المحلي دون حسابات دائمة، والبيانات المحلية التجريبية لا تُحفظ بعد إعادة تحميل الصفحة.
4. لتمكين الحسابات والحفظ الدائم، أنشئ مشروعًا في Supabase.
5. افتح SQL Editor في Supabase والصق محتويات `supabase-schema.sql` ثم Run.
6. من Project Settings > API انسخ Project URL و`anon/public` key.
7. ضع القيمتين في `config.js` بدل النصوص `PASTE_...`.
8. ارفع التعديلات إلى GitHub ثم افتح الموقع مجددًا.

## تثبيت على Android
1. افتح رابط الموقع في Chrome.
2. من قائمة ⋮ اختر Install app أو Add to Home screen.
3. وافق على التثبيت. ستظهر أيقونة HomeCare على الشاشة.

## ملاحظات تشغيل مهمة
- استخدم HTTPS (GitHub Pages يوفر HTTPS) حتى يعمل Service Worker.
- لا تضع مفتاح `service_role` في `config.js` أو أي ملف يصل للمتصفح.
- مفاتيح anon/public مصممة للاستخدام من العميل بشرط تفعيل RLS بشكل صحيح.
- وضع العرض المحلي للتجربة فقط، ويستخدم ذاكرة الصفحة ولا يحفظ بيانات دائمة.
- تنبيهات الأدوية في هذه النسخة عبارة عن سجل للمواعيد وليست إشعارات Push موثوقة في الخلفية.
- لا توجد مشاركة بيانات بين المريض والممرض في هذه النسخة؛ تم منعها عمدًا لحين بناء موافقة صريحة، والتحقق من هوية مقدم الرعاية، وسجل تدقيق.
- لا تستخدم بيانات مرضى حقيقيين أو معلومات تعريفية حساسة في مشروع العرض.
- المحتوى الصحي تثقيف عام وليس تشخيصًا أو وصفة علاجية. يجب مراجعته من أعضاء هيئة تدريس ومختصين سريريين قبل النشر.

## قبل الاستخدام الحقيقي
يلزم على الأقل:
- تقييم أمني مستقل واختبار اختراق ومراجعة إعدادات Supabase وRLS.
- موافقات مؤسسية وقانونية مناسبة لقوانين حماية البيانات الصحية المعمول بها.
- موافقة واضحة وقابلة للسحب من المريض قبل مشاركة ملفه مع أي ممرض/جهة.
- التحقق من هوية وصلاحيات مقدمي الرعاية، وتسجيل عمليات الوصول والتعديل.
- مراجعة سريرية لكل المحتوى ومسارات التنبيه.
- نسخ احتياطي، خطة استجابة للحوادث، سياسة احتفاظ وحذف للبيانات.
- إشعارات خلفية موثوقة وخدمة دعم عند الحاجة.
- اختبار الاستخدام وإمكانية الوصول على أجهزة ومتصفحات متعددة.

## النطاق الحالي
هذه نسخة مشروع تخرج قابلة للتطوير وليست منتجًا طبيًا معتمدًا، ولا تراقب المريض تلقائيًا ولا تستبدل الإسعاف أو الطبيب أو الممرض.
